How it works

Every PNG pixel has four channels — Red, Green, Blue, and Alpha (opacity). This tool exploits all four to smuggle raw bytes into a lossless image that survives upload to Twitter/X without compression.
🎨
Full color palette
Each pixel's RGB channels carry three bytes of your payload — any color is fair game. The entire 16-million-color space is used as a data bus.
👁️
Opacity as data
The alpha channel encodes how many bytes live in a boundary pixel — 255 = 3 bytes full, 170 = 2 bytes, 85 = 1 byte. Fully transparent pixels signal end-of-data.
📐
899 × 898 resolution
Twitter recompresses images above a certain pixel count. 899×898 sits just under that threshold — large enough to hold ~3 MB of data, small enough to pass through untouched.
🔒
Up to 2.31 MiB hidden
With 807,302 pixels × 3 bytes each you can encode files, text, encrypted messages, archives — anything that fits in 2.31 MiB of raw data, right inside a public tweet image.
🌐
Decode from URL
Paste any Twitter/X image URL or bare media ID directly — the tool fetches the PNG from pbs.twimg.com and decodes it client-side, nothing leaves your browser.
